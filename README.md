# GIOAI v6.0 — Multi-Platform Homework Autocompleter

Platform-specific pages:
- **Sparx Maths** → sparx.html (60-70s delay, show working, max 2 tasks)
- **LanguageNut** → languagenut.html (5-8s delay, FCaptcha FAILEDTOKEN bypass)
- **Seneca Learning** → seneca.html (5-8s delay)
- **Notifications** → notifications.html
- **Admin Panel** → admin.html

## Features
- Per-platform HTML pages with specific settings
- Complete selected tasks with checkboxes
- Saved accounts per platform
- Show past homework toggle
- Show working out (Sparx)
- Notifications system for announcements/changelogs
- Admin panel with stats, blacklist (user+platform+password), account management
- 8 themes (Dark, Light, Midnight, Amber, Ocean, Forest, Sunset, Candy)
- Mobile-responsive

## Setup
1. Set worker URL in script.js (S.worker)
2. Push to GitHub Pages
3. Access at your GitHub Pages URL
